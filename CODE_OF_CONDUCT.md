# Code of Conduct

Libre Remote is committed to a respectful, welcoming, technically rigorous community.

## Expected behavior

- treat contributors and users with respect;
- discuss technical decisions in good faith;
- critique code and ideas, not people;
- protect user privacy and never publish sensitive pairing/network data;
- make accessibility and newcomer usability part of engineering quality;
- disclose conflicts of interest when they materially affect a proposal;
- avoid harassment, discrimination, threats, doxxing, sexualized conduct, spam, and deliberate disruption.

## Scope

This applies to repository issues, pull requests, discussions, reviews, release channels and other project spaces where someone is acting as a Libre Remote contributor or representative.

## Enforcement

Maintainers may edit, hide, lock or remove content and may temporarily or permanently restrict participation when behavior is abusive, unsafe, privacy-invasive, deceptive, or persistently disruptive.

For conduct concerns that contain sensitive personal information, use a private maintainer contact rather than a public issue. Security vulnerabilities should follow `SECURITY.md`.

Enforcement decisions should be proportionate, documented internally when practical, and focused on protecting the community and project rather than winning an argument.
