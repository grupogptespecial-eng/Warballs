# Maintainers

The project is currently maintained by the Libre Remote community under the `grupogptespecial-eng` GitHub organization.

## Responsibilities

Maintainers review compatibility claims, security-sensitive protocol changes, release signing configuration, Play Store disclosures, accessibility regressions and dependency updates.

## Decision process

Prefer documented technical evidence, simulator tests and physical device reports. Breaking protocol or persistence changes require migration notes. A manufacturer integration that conflicts with public platform policy must not be enabled merely because it is technically possible.
