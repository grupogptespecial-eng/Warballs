# Third-Party Notices

This file is intentionally release-gated.

Libre Remote depends on third-party libraries, build tooling and platform SDKs. Each remains subject to its own license and attribution requirements.

## Release rule

A Stable or 1.0 source/binary release must not ship with an unreviewed placeholder here. The dependency/license audit must:

1. enumerate direct runtime/build dependencies that are redistributed or materially incorporated;
2. record package/artifact name and version;
3. record license identifier/name and source location;
4. preserve any NOTICE/attribution text required by the dependency;
5. flag unknown, missing, non-commercial, source-available-only, copyleft, or otherwise incompatible terms for human review;
6. include relevant bundled fonts, icons, images and other assets, not only code libraries.

The public-release audit treats the marker below as blocking in strict mode until the canonical source has been materialized and its dependency inventory reviewed.

`THIRD_PARTY_AUDIT_STATUS: PENDING_CANONICAL_SOURCE`
